Device Security

Your phone and computer hold messages, photos, schoolwork and accounts. Securing the device protects everything stored behind it.

Start Learning ↓Test Yourself

💻 Turn Your Device Into a Security Zone

Security works best when software, accounts, apps and backups are protected together.

🔄

Update regularly

Operating-system and app updates often contain security fixes. Install updates from trusted sources.

🔒

Lock the screen

Use a strong device lock and enable automatic locking so someone cannot easily access your data if the device is unattended.

☁️

Keep backups

Back up important school and personal files using a trusted backup method so one lost or damaged device does not mean losing everything.

⚙️ Four Layers of Device Defense

Build habits that protect the device before something goes wrong.

01 — Install from trusted sources

Prefer official app stores and the developer’s genuine website. Avoid pirated or modified software because it can introduce unwanted programs.

02 — Review permissions

Ask why an app needs access to your camera, microphone, contacts or location. Remove permissions that are unnecessary.

03 — Protect removable media

Be cautious with unknown USB drives and files. Scan unfamiliar files and avoid opening unexpected attachments.

04 — Prepare for loss

Use device-finding features and keep recovery information secure. If a device is lost, use the service’s official account controls.
