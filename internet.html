Safe Internet Practices

Safe browsing means checking where you are, what you download and what information a website is asking you to provide.

Start Learning ↓Test Yourself

🌐 Navigate the Web Like a Cyber Detective

Do not judge a website only by how professional it looks. Check the address, context and request.

🔎

Check the domain

Look at the actual website address. Small spelling changes or unexpected domains can be warning signs.

📥

Think before downloading

Unexpected files, cracked software and unknown browser extensions can introduce security risks.

📶

Use networks thoughtfully

On public or untrusted Wi-Fi, avoid sensitive activity when possible and prefer trusted connections.

WEB DEFENSE :: ADDRESS CHECK → REQUEST CHECK → DOWNLOAD CHECK → DECISION

🧭 The Safe-Browsing Flow

Use this quick mental checklist whenever a site asks you to act.

01 — Where am I?

Check the domain and make sure you reached the intended service. For sensitive accounts, navigate from the official app or a trusted bookmark.

02 — What is it asking?

Be cautious if a page unexpectedly asks for passwords, OTPs, payment details or unusual permissions.

03 — What am I downloading?

Do not install unknown executables, extensions or pirated software just because a pop-up says they are required.

04 — When in doubt, leave

Close the page and verify through an official source. A few seconds of checking can prevent a much bigger problem.

🔐 HTTPS note: HTTPS encrypts traffic between your browser and a website, but it does not by itself prove that the website is trustworthy. The domain still matters.
